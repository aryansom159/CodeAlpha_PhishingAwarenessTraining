# 🛡️ Phishing Awareness Training

## 📌 Project Overview
This project was developed as part of the **CodeAlpha Cyber Security Internship**. It is an interactive web-based application designed to spread awareness about phishing attacks and educate users on how to identify and avoid online scams.

## ✨ Features
- Introduction to Phishing
- Types of Phishing Attacks
- Fake Email Example
- Cybersecurity Safety Tips
- Interactive Quiz
- Simple and User-Friendly Interface
- Responsive Design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
```
CodeAlpha/
│── index.html
│── README.md
```

## 🚀 How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Double-click **index.html** or open it using Live Server in VS Code.
4. Explore the phishing awareness content and take the quiz.

## 🎯 Learning Outcomes
- Understanding phishing attacks
- Recognizing fake emails and websites
- Following cybersecurity best practices
- Improving online safety awareness
